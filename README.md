# 🗄️ Laboratorio 2 – Arquitectura de Datos

**Estudiante:** Karen Mina  
**Asignatura:** Arquitectura de Datos  
**Universidad:** Universidad Dr. José Matías Delgado

## 🎯 Objetivo

Demostrar el dominio del proceso de gestión y análisis de datos: desde la conexión y carga correcta de una base de datos, hasta su preparación, transformación y visualización para apoyar la toma de decisiones empresariales.

## ⚙️ Proceso desarrollado

1. **Conexión y carga:** conexión a PostgreSQL y gestión de las tablas.
2. **Preparación de datos:** limpieza, revisión y transformación mediante Databricks o Power BI.
3. **Modelado:** organización de tablas y relaciones.
4. **Medidas DAX:** creación de indicadores y cálculos para el análisis.
5. **Dashboard:** diseño de visualizaciones que respondan preguntas reales de negocio.

## 📊 Preguntas de negocio

- ¿Qué servicios y repuestos concentran la actividad?
- ¿Qué servicios o repuestos generan mayor importe completado por sede?
- ¿Cómo cambia el número de operaciones completadas por mes?
- ¿Qué segmentos concentran mayor importe por categoría?

## 🛠️ Herramientas

- PostgreSQL / Neon
- Power BI Desktop
- DAX
- GitHub

## 💡 Resultado esperado

Transformar datos en información útil mediante un flujo de trabajo que permita comprender, analizar y comunicar resultados para respaldar decisiones de negocio.
